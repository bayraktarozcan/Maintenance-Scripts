# Code of Conduct / Davranış Kuralları

> **Language / Dil:** [English](#en) · [Türkçe](#tr)

---

<a id="en"></a>

## English

Everyone participating in this project behaves respectfully and constructively. Zero tolerance for harassment, insults, and personal attacks.

**Expected:** respect for differing views, kind language, focus on solutions not blame.
**Unacceptable:** insults, discrimination, persistent harassment, sharing private information without consent.

Report violations privately via [Security Advisory](https://github.com/bayraktarozcan/Maintenance-Scripts/security/advisories/new). Maintainers apply proportionate enforcement including warnings, temporary bans, or permanent bans.

*Adapted from [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1.*

## Türkçe

Bu projeye katılan herkes saygılı ve yapıcı davranır. Taciz, aşağılama ve kişisel saldırıya sıfır tolerans uygulanır.

**Beklenen:** farklı görüşlere saygı, nazik dil, hataya değil çözüme odaklanma.
**Kabul edilmez:** hakaret, ayrımcılık, ısrarlı taciz, özel bilgiyi izinsiz paylaşma.

İhlalleri [Security Advisory](https://github.com/bayraktarozcan/Maintenance-Scripts/security/advisories/new) üzerinden gizli bildirin. Bakımcı; uyarı, geçici uzaklaştırma veya kalıcı yasaklama dahil orantılı yaptırım uygular.

*Bu metin [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 2.1 sürümünden uyarlanmıştır.*
